
# 🧠⚡ تحدي القضايا المنطقية والبرهان — Multiplayer

هذه النسخة تستخدم **Node.js + WebSocket** وخادم مركزي. لا تعتمد على WebRTC أو Supabase أو Firebase، لذلك اللاعبان يتصلان بالخادم نفسه حتى لو كان كل واحد على شبكة مختلفة.

## تشغيل محلي
```bash
npm install
npm start
```
ثم افتح `http://localhost:10000`.

## النشر على Render
1. ارفع مجلد المشروع إلى GitHub.
2. في Render اختر New → Web Service.
3. اربط مستودع GitHub.
4. Build Command: `npm install`
5. Start Command: `npm start`
6. بعد النشر افتح رابط Render. لا تحتاج Netlify لهذه النسخة لأن Node.js يخدم اللعبة والخادم من الرابط نفسه.

## مميزات Multiplayer
- غرف من 4 رموز.
- لاعب مضيف + لاعب ضيف.
- الخادم هو المصدر الوحيد للوقت والأسئلة والنقاط.
- السؤال والبدء والنهاية والانتقال متزامنة.
- الإجابة الصحيحة لا تُرسل للمتصفح قبل انتهاء السؤال.
- لا يمكن للمتصفح احتساب نقاطه بنفسه.
- 15/20/30/45 ثانية.
- 5–30 سؤالًا.
- مستويات: تأسيسي، تطبيق وتحليل، تفكير عميق، مزيج.
- مراجعة الأخطاء.
- أكثر من 100 سؤال مولد من قوالب مختلفة، مع تفسير وقاعدة وخطأ شائع.

## ملاحظة
الخدمة المجانية قد تدخل في وضع السكون حسب سياسة الاستضافة؛ عند أول فتح قد تحتاج بضع ثوانٍ حتى يستيقظ الخادم.
